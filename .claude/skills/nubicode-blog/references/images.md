# Images: diagrams, covers, thumbnails, site share image

Everything is generated by `scripts/render-images.mjs` (headless Google Chrome + network for the Inter font; `sharp` from node_modules). Outputs go to `public/images/<slug>/`:

| File | Size | Used for |
|---|---|---|
| `cover.png` | 1200×627 | og:image / LinkedIn & X preview, RSS enclosure + media:content. Has the title on it. |
| `diagram.png` | 1200×H at 2x | in-post `<figure>`; also in RSS content |
| `diagram-thumb.png` | 1200×600 | index card thumbnail: diagram body only (no title band/footer) on flat `--bg`, fitted whole into 2:1 |
| `public/images/og-blog.png` | 1200×627 | site share image: homepage, 404, any page without a cover |

## Add images for a new post

1. Add an entry at the top of the `posts` object in `scripts/render-images.mjs`:
   ```js
   "<slug>": {
     cover: { label: "AI agents", title: "<post title>", accent: "<one short line, a number if possible>", sub: "blog.nubicode.com" },
     diagram: [1200, 720, "<EYEBROW>", "<one-sentence diagram title>", [ ...primitives ].join("")],
     alt: "<full sentence description of the diagram for screen readers and LLMs>",
     caption: "<one sentence>",
   },
   ```
   Primitives: `node(x,y,w,h,title,subLines,variant)` (variants `default|accent|code|muted`), `group(x,y,w,h,label)`, `arrow(points,{label,color,dashed,blocked,lx,ly})`, `pill(x,y,w,n,label,sub)`, `text(x,y,str,opts)`. Canvas is 1200 wide; content between y≈130 and H−70; margins 60.
2. Render: `node scripts/render-images.mjs <slug>` (cover + diagram + thumb). Flags: `--thumbs-only`, `--site-only` (og-blog.png).
3. **Look at both PNGs** (Read tool). Common fixes: subtitle text overflowing a node (shorten it), arrow labels on top of group labels (move `lx/ly` or reroute), title too long for the diagram header.
4. Insert the figure in the post and the frontmatter fields. One-off script pattern used so far:
   ```js
   import { posts } from "./scripts/render-images.mjs";
   const p = posts[slug];
   const fig = `<figure class="diagram">\n  <img src="/images/${slug}/diagram.png" alt="${p.alt}" width="${p.diagram[0]}" height="${p.diagram[1]}" loading="lazy" decoding="async" />\n  <figcaption>${p.caption}</figcaption>\n</figure>\n`;
   // frontmatter: image: /images/<slug>/cover.png  imageAlt: "<title> — <accent>"
   ```
   Escape `"` and `&` in the alt attribute.

## Caching when changing an existing image

Images are served `max-age=86400` and cached by the service worker; LinkedIn caches previews much longer.
- Thumbnails are cache-busted automatically (index adds `?v=<sha256>`).
- **Changing an existing `cover.png` or `diagram.png`**: prefer a new filename (`cover-v2.png`) and update the frontmatter / figure `src`. Then re-scrape in LinkedIn Post Inspector.

## Design rules

DESIGN.md tokens only (`--bg #F0F2F7`, ink `#1A1A2E`, accent `#4768F2`/`#6B8EFF`, Inter 700–900), glass panels, logo `public/logos/NubiCode responsive-03.png` bottom-left, ≥64px margins on covers. No AI-generated imagery, no stock photos.
